# U2-ejercicio16
### Ejercicio: Sistema de Reservas de Cine y Salas
**Objetivo:** Implementar la comunicación entre objetos en Java mediante el envío de mensajes entre una plataforma de reservas y una sala de cine, permitiendo verificar la disponibilidad y bloquear múltiples butacas seleccionadas por un usuario.

Desarrollo de un sistema de reservas de cine utilizando las clases `Butaca`, `SalaCine`, `PlataformaReserva` y `Main` para gestionar la disponibilidad de los asientos, realizar reservas múltiples y actualizar el estado de las butacas seleccionadas.
